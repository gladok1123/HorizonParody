Horizon, офлайн-сборка: Minecraft Java Edition 26.3, переписанный на Rust
==========================================================================

Horizon — неофициальный фанатский проект. Он не связан с Mojang Studios и
Microsoft и не одобрен ими. Minecraft — товарный знак Mojang и Microsoft.
В этой папке нет кода, текстур и звуков Minecraft: Horizon готовит их из вашей
собственной копии Minecraft Java Edition.

В этой сборке нет лаунчера и нет входа в аккаунт. Вы выбираете имя игрока и
играете: одиночная игра, локальная сеть и серверы, которые не проверяют
аккаунты (online-mode=false). Сервер с проверкой аккаунтов такое имя не
пустит, как и любого игрока без входа.

Что нужно для первого запуска
  1. Minecraft Java Edition 26.3 на этом компьютере, скачанный лаунчером,
     которым вы играете: официальным, PineconeMC (ElyPrismLauncher) или Prism
     Launcher. Запустите в нём 26.3 один раз, чтобы лаунчер скачал файлы игры.
  2. Java 25 JDK (именно JDK, а не только среда выполнения: при первом запуске
     javac компилирует собственные экспортёры Horizon), например Eclipse
     Temurin 25 с adoptium.net. Java, которую лаунчер сам скачивает для игры, —
     только среда выполнения, она не подойдёт.

Как играть
  Windows: двойной щелчок по play.bat.     Linux: ./play.sh
  Первый запуск спросит имя игрока (оно хранится в player-name.txt; удалите
  файл, чтобы выбрать другое), подготовит ресурсы (несколько минут, один раз)
  и запустит игру. Следующие запуски сразу открывают игру.
  Миры, настройки, снимки экрана и журналы лежат здесь, в папке game.

Где он ищет ваш Minecraft
  Скрипт запуска и horizon-prepare смотрят по порядку:
    - папку из переменной HORIZON_MINECRAFT_DIR, если она задана;
    - папку из первой строки файла minecraft-dir.txt в этой папке;
    - папку официального лаунчера;
    - папку данных PineconeMC: %APPDATA%\ElyPrismLauncher в Windows,
      ~/.local/share/ElyPrismLauncher в Linux (а также его папки Flatpak и
      snap и переменную ELYPRISMLAUNCHER_DATA_DIR);
    - папку данных Prism Launcher (PrismLauncher в тех же местах);
    - папки ATLauncher и приложения CurseForge.
  Портативный PineconeMC или Prism Launcher хранит файлы там, куда его
  распаковали (в папке UserData, если она есть), MultiMC тоже: впишите эту
  папку в minecraft-dir.txt. В PineconeMC и Prism Launcher её открывает
  пункт меню Folders > Launcher Root Folder (корневая папка лаунчера).
  Каждый файл сверяется с контрольными суммами из research-lock.json, поэтому
  файлы должны быть оригинальными файлами 26.3, каким бы лаунчером они ни
  были скачаны.

Что делает первый запуск
  Он выполняет в этой папке:
    horizon-prepare --prepare --complete
  С официальным лаунчером нужен ещё серверный jar версии 26.3. Скрипт запуска
  ищет server.jar в этой папке; если его нет, скачивает по адресу из файла
  versions/26.3/26.3.json вашего лаунчера (downloads.server.url, загрузка с
  серверов Mojang). Можно положить файл самому под именем server.jar или
  указать путь в переменной HORIZON_SERVER_JAR. Для PineconeMC, Prism Launcher
  и MultiMC он не нужен.
  Остальные параметры: horizon-prepare --help.

Запуск игры вручную
  horizon-client --resources .local/horizon-client/26.3 --game-dir game --name ИМЯ
  Параметры: horizon-client --help.

Управление: мышь — обзор, WASD — движение, пробел — прыжок, левый Shift —
красться, левый Ctrl — бег, левая кнопка — ломать, правая — ставить или
использовать, 1-9 или колесо — панель предметов, E — инвентарь, Q — выбросить,
F1 — скрыть интерфейс, F3 — отладка, Esc — пауза.

Ещё в этой папке
  horizon-ctl     управляет игрой из терминала или скрипта (horizon-ctl help)
  horizon-server  запускает сервер на этом же движке:
    horizon-server --dir my-server init
    horizon-server --dir my-server start
  Его настройки — в my-server/server.toml; игроки этой сборки зайдут только
  при online_mode = false.
